# 🐚 Bash & Linux Scripting Exercises

A collection of Bash scripts and notes covering core Linux shell scripting topics: commands and arguments, environment variables, variable expansion, and file permissions.

## 📂 Topics Covered

- ⌨️ **Commands And Argumments** - running commands, I/O redirection (`>`, `>>`, `2>`, `2>&1`), piping, and handling command output/errors
- 🌱 **Environment Variables** - setting, exporting, and unsetting shell and environment variables, working with `PATH`
- 🧰 **Important Linux Commands** - useful everyday commands like `alias` and `ps`
- 🔐 **Permissions And Ownership** - changing file ownership (`chown`) and permissions (`chmod`)
- 🔤 **Variables And Expansions** - parameter expansion, string manipulation, arrays, and positional arguments
